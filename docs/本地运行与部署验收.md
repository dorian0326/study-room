## 1. 启动网页版

工作目录为项目根。使用用户指定conda环境，当前已安装所需Python依赖；前端依赖已存在。如换机器，Python3.12安装`backend/pyproject.toml`的`.[dev]`，Node20+在frontend执行npm ci。当前本机实际Node22，与CI Node20需区分。

```powershell
conda activate webdev_3.12
python scripts/course_demo.py
```

也可不用激活，显式解释器：

```powershell
& 'C:\Users\zjb\.conda\envs\webdev_3.12\python.exe' scripts/course_demo.py
```

脚本先构建Vue，再在独立`backend/data/course_demo.db`迁移与幂等导入合成演示数据，最后启动本机回环8000端口。浏览器打开[网页版](http://127.0.0.1:8000/)，[Swagger](http://127.0.0.1:8000/docs)，[健康检查](http://127.0.0.1:8000/api/health)。`--skip-build`复用已构建dist，`--port 8001`可换同源端口，`--prepare-only`只准备。不会选中或清空原`study_room.db`，不做隐式重置。

本次演示服务已在后台启动，PID记录于`evidence/20261125/demo-process-id.txt`，stdout/stderr同目录；关机或退出进程后按上述命令重启。停止前确认进程是本次uvicorn，不要按端口盲杀其他服务。前台运行可Ctrl+C正常关闭。

## 3. 重复执行验证

```powershell
conda activate webdev_3.12
cd backend
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
python -X utf8 -m pytest -q --tb=short --basetemp .venv/course-test
python -m ruff check .
python -m ruff format --check .
cd ../frontend
npm run lint
npm run format:check
npm run build
cd ..
python -X utf8 scripts/export_design.py
python -X utf8 scripts/verify_http_delivery.py
```

最后一条会在全新临时SQLite和随机本机端口执行真实HTTP完整链、200客户端查询/抢座及停服恢复；不向公共演示站发负载。脚本按实际当前时间预约，需要在所设06:00～22:00运行；超出时间明确失败，不伪造时钟。性能原始样本与状态/目标在JSON，P95失败不会改阈值。

## 4. 部署边界与验收状态

本次仅本机127.0.0.1，不开放局域网/公网，不触碰旧线上站。部署外部环境需要生产密钥、HTTPS、服务管理、备份频率/保留及访问控制；未进行真实校园接口或生产故障演练。

静态SPA在已有dist时自动挂载，未知/api返回JSON404，不回退为页面。静态文件路径限制在dist，媒体按构建产物提供。数据库备份为SQLite一致快照；恢复在停服隔离库逐表对账，仅证明回到快照，RPO0未实现。

当前技术实测和已知失败见[测试报告](testing/软件测试报告.md)。学生交叉审查、阶段验收、最终课程批准尚待真实人员完成，不能把网页可运行当作全部NFR和课程验收通过。
