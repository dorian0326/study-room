## 变更与复核约定

1. 业务或课程范围问题由项目组指定的真实确认人答复；AI 不代替确认。
2. 每项决定同步到受影响的需求、接口、状态、数据和测试说明，再由另一名成员复核。
3. 已接受的 ADR 后续改变时新增替代记录，保留旧记录和替代关系。
4. 提交后由维护人把本索引中的代码基线更新为真实提交标识；不要预填当前文档自己的哈希。
