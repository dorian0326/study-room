## 2. 范围与版本

## 3. 确认与人工责任

业务确认身份为“当前对话用户（真实姓名和项目内职务未提供）”，依据为本轮直接答复；不伪称教师/组长批准。AI为Codex，承担候选设计、代码和测试执行。模块学生负责人、另一成员交叉审查人、课程验收人均待项目组填写。没有这些签认时，课程阶段验收保留“待人工核验”。

无需等待所有Q才做无关工作：缺陷中与明确BR/权限/数据不变量一致的修复和测试可推进；预约时长/改时段、撤销降级政策、学校授权材料、恢复指标等仍需针对性记录，不擅自扩大范围。
