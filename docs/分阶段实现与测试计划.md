## 2. 测试安排

环境优先用户指定conda webdev_3.12；Python3.12、Node22及实际包版本写执行证据。pytest使用临时文件型SQLite、Alembic迁移、独立Session、合成用户，关闭后台并显式触发；不写原study_room.db。

编码前：原需求/用户决定对应预期，见[用例](testing/软件测试用例.md)。编码中：每个任务边界/异常/权限/数据库后置；每次修改后跑受影响回归。阶段后：真实HTTP/浏览器纵向主链、关键异常与原套件；最终：构建后同源部署、媒体、备份恢复、获准本地隔离负载。性能固定以P95<=2秒、200并发及零超售为目标，结果未达不改阈值；月度可用率与可信NTP不在短时演练中伪称通过。

自动化工具pytest、FastAPI TestClient、真实HTTP客户端、浏览器UI工具；新依赖仅安装到用户授权环境。前端build不能替代网页业务测试。测试失败保留原文，修实现与修测试依据分开记录；不为了全绿删约束。
