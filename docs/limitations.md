# 已知限制与实现说明

本文说明课设实现与需求文档之间**有意保留**的差异，避免把模拟能力写成真实能力。

## 1. 门禁为模拟接入（需求项 7 / US-014）

当前提供：

- 运维接口接收脱敏后的 mock 进出事件（`POST /api/ops/entry-exit/mock`）
- 记录查询与人工核验申请
- 前端「出入馆」页可查看记录并写入模拟事件

**未实现**（也不假装实现）：

- 真实闸机 30 秒轮询
- ≤5 分钟延迟判定与自动降级链路
- 与校园一卡通 / 人脸闸机的生产对接

部署文档与演示应明确标注「门禁为模拟」。

## 2. 并发控制方式（需求项 10 / BR-013 相关）

需求原文倾向乐观锁（版本字段）。本仓库在 SQLite 上采用：

- `BEGIN IMMEDIATE` 写事务（`app.db.transaction(immediate=True)`）
- 创建预约的幂等键（`Idempotency-Key` / `request_key`）

**结果正确**（冲突返回 409、同幂等键可安全重试），但实现机制不是乐观版本号。若课程验收要求对照原文，请以本节为准说明。
