# 任务卡模板

复制本文件并为任务命名。也可以直接在 GitHub Issue 中填写同等字段；任务状态以 Issue 为准，不在仓库重复维护两套状态。

| 字段 | 填写内容 |
| --- | --- |
| 任务编号/名称 | TASK-__ / __；GitHub Issue：#__ |
| 负责人/审查人 | __ / __ |
| 关联阶段、需求、ADR、接口和测试 | __ |
| 目标 | 一句话描述可观察业务结果：__ |
| 输入基线 | 文档路径、版本或真实提交标识：__ |
| 允许修改 | 模块/文件范围：__ |
| 禁止修改 | 未批准规则、范围外模块、验收预期等：__ |
| 前置依赖 | 任务、Q、环境：__ |
| 事务、权限、幂等约束 | __ |
| 必执行测试 | 命令、测试案例编号及预期：__ |
| 完成标准 | 代码、测试证据、文档更新、人工审查：__ |
| 停止条件 | 需改需求/接口/架构或新增依赖时先反馈：__ |
| 状态 | 待准备 / 可开始 / 实现中 / 待审查 / 需修改 / 已完成 |
