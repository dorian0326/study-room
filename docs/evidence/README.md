# 测试与审查证据

此目录用于保存精选、可复核的验证材料。当前目录尚无执行日志、交叉审查记录或阶段验收单；文档中列出的测试案例不代表已经执行，也不代表人工业务预期已经确认。

## 每份记录至少包含

- 任务、测试案例、阶段及关联需求/接口/Q/ADR。
- 代码提交标识、环境和数据库类型；涉及并发时记录真实文件数据库和独立连接数。
- 实际执行命令、开始时间、原始结果及失败处理。
- 执行人和独立审查人；业务预期的确认人、身份、依据和日期。
- 证据文件链接以及未执行项和残余风险。

## 文件约定

可使用日期和任务号命名，例如 2026-11-12-TASK-LOCAL-001-test.md。只提交必要输出；测试数据使用合成账号和合成业务内容，隐藏令牌、密码、学号、真实门禁标识和个人信息。截图只作为辅助，不替代命令、版本和原始测试结果。

阶段验收单应记录演示主流程、关键异常、前阶段回归、自动测试、人工检查、Q/ADR/接口变更、残余风险、验收结论及真实验收人。
